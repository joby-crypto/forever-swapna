FOREVER, SWAPNA — TWO VERSIONS

desktop/index.html — refined desktop layout, automatically adapts to phones too.
mobile/index.html — mobile-first layout with extra spacing and simplified flower foreground.

To publish one version on GitHub Pages: copy the index.html from your chosen folder to the ROOT of your GitHub repository.

Music: put a file named music.mp3 next to index.html. The music button appears when the browser can load it. Playback requires a tap.

All garden illustrations are built into the HTML; no images required. Google Fonts needs an internet connection, with fallback fonts if offline.
